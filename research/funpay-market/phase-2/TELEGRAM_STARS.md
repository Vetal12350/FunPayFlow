# Telegram Stars: стоимость и выбор поставщика

## Что подтверждено

Публичный RSC_STARS показывает единую ставку **$0.015 за Stars** и доставку по @username. Это наиболее конкретный доступный ценовой ориентир в этом исследовании, но не зафиксированный all-in quote или доказанный самый дешёвый поставщик. У KRAB.GG, TgSuperstars и iFragment нет сопоставимого действующего персонального тарифа. Выбрать победителя по реальной себестоимости нельзя.

Приоритет для получения retail и quote:500, затем 2500, затем 100. Больше номинал не даёт скидки за звезду в этом public table. ## Поставщики и комиссии: разные виды цены

| Поставщик | Доказанные условия / тип цены | Что мешает сравнить полную стоимость |
|---|---|---|
| ReSellCodes | .0150 public catalog; min funding$3; USDT TRC20/BEP20/TON/Aptos; individuals18+ general | Quote/account price, actual network/funding fee, UA eligibility и issuer chain |
| KRAB.GG | Публикует Fragment+1%; USDT TON min100; price API | Не получен текущий quote; +1% не накладывать второй раз на готовую котировку; соответствие Binance TON проверить |
| TgSuperstars | Одна цена всем партнёрам; activation$10; на TRC20/BEP20/Arbitrum депозит+1USDT; баланс не выводится | Текущая цена/звезда после activation; fee зависит от сети/депозита; UA eligibility |
| iFragment | PLATFORM рекламирует «от$.0165»; API example не quote | Действующая цена и сеть USDT; OWN10%service — другая модель, не добавка к PLATFORM |
| YuPay | No-company program в общем виде, Stars/API | Цена, funding USDT и принятие UA безФОП UNKNOWN |

При прочих равных .0150 меньше рекламного «от.0165», но это сравнение **двух публичных утверждений**, а не арбитражная котировка. Для Tg депозитная 1USDT делится на фактические выполненные заказы, финансируемые этим депозитом; это не обязательная 1USDT на каждый заказ. Не считать min100USDT KRAB расходом 100 USD на один SKU; это замороженный капитал. Не считать activation$10 подтверждённой невозвратной комиссией без уточнения назначения.

## Fragment и допустимая выдача

TG_STARS_API/TG_STARS_TERMS подтверждают официальные purchase/gift flows. Fragment buy page вернул 403, KRAB price endpoint не дал данных; проверки остановлены. Текущая стоимость TON, сетевой gas и fee прямой покупки UNKNOWN. Распространённую 5% fee не переносить из операций продажи/вывода или аукционов на покупку Stars. Публичный Telegram Bot API для приёма/возврата Stars сам по себе не API оптовой выдачи на произвольный username.

Использовать только PLATFORM/разрешённый supplier gift flow без session покупателя. Username нормализуется, resolving должен вернуть получателя; пользователь подтверждает имя/аватар/ID, если доступно разрешённым API. Valid username не доказывает, что он принадлежит покупателю. Ошибочная отправка существующему аккаунту обычно необратима; отсутствие/смена username — MANUAL_REVIEW до покупки. API-поля и пределы количества брать из действующего контракта: у RSC на странице расходятся max10000 и 100000, запросить лимит.

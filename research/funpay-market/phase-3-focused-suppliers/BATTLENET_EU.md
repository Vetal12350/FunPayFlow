## C2. WoW60 Days Game Time Europe — обязательный отдельный SKU

Первичный indexed EU shop содержит именно 60 Days Game Time, с ориентиром€25.98 retail. Это не актуальный wholesale quote и не доказательство stock-кодов у любого поставщика. В таблице экономики выбран WOW60EU, все procurement/actual-profit поля UNKNOWN.

| Кандидат | Реально установленное evidence | Чего нет |
|---|---|---|
| CJS Wholesale | Старый WoW60 request и referral; публичный GBP100deposit/MOQ5; API claim | Exact EU batch price/stock/region, instant API, crypto funding |
| Worldofcdkeys | Существующий WoW60 inquiry в SENT | Supplier confirmation/quote/API/provenance |
| KORSIT/dundle | Retail page описывает 60days, selected US locale no stock; новый запрос EU | Текущая EU code availability и wholesale/API permission |
| CodesWholesale | Реальный ответ KYB/EUR30/company bank | Не подходит без компании; новый запрос не отправлен |
| epay | Уже был distribution request | Действующий downstream route/contract |

WoW Game Time добавляет срок игры; не Balance, не recurring subscription и не expansion. Не покупаем аккаунт, не просим пароль и не используем стороннюю карту для оформления подписки. Техническая выдача code может быть мгновенной только после подтверждённого supplier stock либо предварительного лицензированного inventory.

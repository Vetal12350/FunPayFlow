# Безопасность FunPayFlow v1.0

О предполагаемых уязвимостях сообщайте **приватно** через GitHub Private
Vulnerability Reporting на вкладке Security, когда владелец включит эту
функцию для репозитория. До подтверждения её доступности не раскрывайте
неисправленную уязвимость публично: дождитесь согласованного рассмотрения.
Обычные ошибки и предложения функций размещайте в GitHub Issues.

Никогда не прикладывайте к публичным issues, PR или сообщениям:

- `.env`, значения `FUNPAY_GOLDEN_KEY` и `BOT_TOKEN`;
- `PHPSESSID` и другие session cookies, CSRF и прочие данные сессии;
- `state.sqlite3` и другие базы данных;
- приватные логи со сведениями об аккаунте или заказах;
- экспорты продаж FunPay и приватные резервные копии;
- закрытые SSH-ключи.

Личный адрес электронной почты для security reporting не объявлен.

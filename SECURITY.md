# Безопасность FunPayFlow v1.0

О предполагаемых уязвимостях сообщайте **приватно** через включённый для этого
репозитория GitHub Private Vulnerability Reporting (вкладка Security → Report a
vulnerability). Не раскрывайте неисправленную уязвимость в публичном Issue
или Pull Request. Обычные ошибки и предложения функций размещайте в GitHub Issues.

Никогда не прикладывайте к публичным issues, PR или сообщениям:

- `.env`, значения `FUNPAY_GOLDEN_KEY` и `BOT_TOKEN`;
- `PHPSESSID`, другие session cookies, CSRF-токены и прочие значения сессии;
- `state.sqlite3` и другие базы данных;
- приватные логи со сведениями об аккаунте или заказах;
- экспорты продаж FunPay и приватные резервные копии;
- закрытые SSH-ключи.

Личный адрес электронной почты для security reporting не объявлен.

# Control Center: запуск без консоли (Windows)

Этот документ относится к **необязательному** графическому интерфейсу для локального Codex Worker.
Запуск GUI сам по себе не запускает Worker, не устанавливает зависимости,
не обновляет исходники, не обращается к production VPS и не меняет состояние бота.

## Запуск

1. Установите UI согласно [CONTROL_CENTER.md](CONTROL_CENTER.md), если это ещё не сделано.
2. После ревью и штатного обновления локального исходного checkout дважды нажмите
   `scripts/start_control_center_silent.vbs` в Проводнике.
3. При необходимости создайте **ярлык** этого файла на рабочем столе.

Этот ярлык вызывает изолированный UI Python 3.13 `pythonw.exe` через Windows Script Host.
Он открывает окно CustomTkinter без чёрной консоли. Предыдущий
`scripts/start_control_center.bat` **оставлен без изменений** и подходит
для диагностики, если GUI не открывается или Windows Script Host отключён.

При отсутствии UI-окружения или файлов стартера показывается сообщение об ошибке.
При неудачном старте самого Python GUI выводится одно нейтральное окно с инструкцией
открыть диагностический BAT. Содержимое исключений, логи Codex, секреты и пути
учётных данных пользователю не показываются.

## Безопасность и ограничения

- Ничего не устанавливается автоматически; `setup_control_center_ui.ps1` запускается только вручную.
- Открытие/закрытие окна не запускает и не завершает существующий Worker.
- Текущие защиты от повторного запуска Worker и неопределённого heartbeat не меняются.
- Это только удобный запуск **уже установленного** UI. Не нужно запускать несколько экземпляров Control Center.
- Smoke-проверка на Windows обязательна до замены привычного ярлыка;
  WSH может быть отключён политиками компьютера. В этом случае используйте BAT.
- Изменение не делает текущий Worker универсальным: поддержка нескольких репозиториев
  отслеживается в GitHub Issue #139, редизайн — Issue #140.

## Windows: чистая установка из ZIP

- [ ] На чистой Windows 10/11 с отдельным тестовым аккаунтом скачайте
      `FunPayFlow-v1.0.0.zip`; сравните SHA-256 с `.zip.sha256`.
- [ ] Распакуйте в путь с пробелами, например `C:\Test Bot Release\v1.0.0`.
- [ ] Запустите `Setup.bat` без прав администратора. Проверьте скрытый ввод
      токена и golden key; убедитесь, что в консоли нет их значений.
- [ ] Проверьте `%LOCALAPPDATA%\FunPayFlow`: там `.env`; после запуска
      там же настройки, SQLite, lock и `logs/`, а не в папке ZIP.
- [ ] Запустите `Start.bat`, отправьте `/start`. Проверьте мастер, десять
      выбранных модулей, сохранение и перезапуск.
- [ ] Убедитесь, что валюта задаётся в Статистике/Аналитике, а не в Модулях.
- [ ] Запустите второй `Start.bat`, пока первый работает: он должен завершиться
      с понятным сообщением о process lock, без второго бота.
- [ ] Остановите первый процесс и запустите снова; настройка не повторяется,
      история и выбранные модули сохранены.
- [ ] Повторите `Setup.bat`, откажитесь от редактирования `.env`; сравните
      байты `.env` и SQLite до/после.
- [ ] Распакуйте тот же ZIP в **другую** папку с пробелами, запустите её Setup
      и Start: данные остались теми же, ручное копирование не понадобилось.
- [ ] Проверьте остановку, резервную копию каталога данных и восстановление
      на отдельной тестовой копии.

## Ubuntu/VPS: чистая установка из ZIP

- [ ] На чистой поддерживаемой Ubuntu создайте обычного тестового пользователя;
      распакуйте ZIP в путь с пробелами отдельно от папки приватных данных.
- [ ] Сравните SHA-256. Выполните `bash -n linux/install.sh`.
- [ ] Запустите `linux/install.sh --code-dir ... --data-dir ...` без root; убедитесь,
      что зависимости поставлены из `uv.lock`, `.env` имеет права `600`,
      каталог данных — `700`.
- [ ] Сгенерируйте unit через `python -m funpayflow.render_service` с тестовыми путями и выполните
      `systemd-analyze verify` для unit. Проверьте WorkingDirectory,
      ExecStart, EnvironmentFile, пользователя и отсутствие значений секретов.
- [ ] Установите через `--systemd`; только интеграция с systemd использует
      `sudo`. Проверьте `systemctl status funpayflow` и
      `journalctl -u funpayflow.service -f`.
- [ ] Отправьте `/start`, завершите мастер и проверьте Telegram Restart:
      один runtime, без второго процесса.
- [ ] Проверьте `systemctl stop` (SIGTERM), `start`, `restart`; при включённом
      сервисе перезагрузите тестовую VM и убедитесь в автозапуске.
- [ ] Остановите сервис, сделайте backup всей папки данных, установите новый
      код в другую папку с тем же `--data-dir`, вручную обновите unit и
      проверьте сохранность истории и настроек.

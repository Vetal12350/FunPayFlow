Установленная FunPayAPI 1.1.0 имеет только `get_lot_fields(lot_id)` → `offerEdit?offer=...`, без `node_id`/blank create-form; `LotFields.renew_fields()` не сбрасывает `offer_id`, `save_lot()` не возвращает новый ID. Нельзя безопасно включить создание по контракту другой версии. Publish явно заблокирован, modifying HTTP не выполняется; ни одна категория не объявлена поддержанной для публикации. Для продолжения нужен проверенный create-form contract установленной версии; dependency не модифицировалась. Success/timeout/UNKNOWN publish verification не объявлены реализованными или проверенными.
- Важные границы: UNKNOWN не доказывает failure/success; после crash возможен консервативный пропуск поднятия на safe window. Время cooldown зависит от wall clock. Active polling recovery не равен startup retry. Сохранённый legacy OFF не имеет provenance — нельзя автоматически угадать намерение пользователя.

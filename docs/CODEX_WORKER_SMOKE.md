# Smoke-тест локального Codex worker

Локальный worker, разрешённый владельцем, обрабатывает задачу по цепочке:
GitHub Issue → изолированный source checkout с Codex CLI → офлайн-проверки CI → PR.
Codex читает инструкции проекта и меняет только разрешённые исходники или
документацию. Проверки выполняются с mocks/fakes и временными данными;
доверенный worker затем создаёт PR для ревью перед слиянием.

Этот smoke-тест добавляет только данную заметку. Он не выполняет сетевых
запросов, реальных операций FunPay/Telegram, SSH-подключений, действий на VPS
или в production; credentials и приватные runtime-данные не используются.

При входе в Codex CLI через ChatGPT API key не нужен. Можно использовать
план ChatGPT Plus с учётом действующих лимитов использования; подписка
не означает неограниченную работу CLI.

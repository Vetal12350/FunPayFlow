# FunPay Seller Bot

Бот для продавца FunPay с управлением через Telegram. Он отслеживает заказы,
сообщения и отзывы, сохраняет историю в SQLite, показывает статистику и
аналитику продаж, импортирует официальный экспорт и поддерживает управляемое
автоподнятие лотов. Встроенные модули можно включать и выключать; SAFE_MODE
блокирует автоматические изменяющие действия.

Проект рассчитан на Python 3.13 и Windows/Linux. Публичные установщики и
пошаговая пользовательская инструкция готовятся в следующем пакете. Сейчас
запуск требует ручной конфигурации: перечень переменных есть в
`.env.example`. Не публикуйте заполненный `.env`, базу, настройки или логи.

## Разработка

Установите [uv](https://docs.astral.sh/uv/getting-started/installation/),
затем в каталоге проекта выполните:

```text
uv sync --locked --dev
uv run --no-sync pytest -q
uv run --no-sync python tests/packaging_smoke.py
```

Последняя команда собирает исходный архив и wheel, устанавливает wheel во
временное окружение и проверяет импорты и entrypoint без запуска бота и без
сетевых запросов. Она использует пакеты, уже загруженные при `uv sync`.

# FunPayFlow

**Автоматизация, аналитика и управление продажами FunPay через Telegram**

Бесплатный бот для продавцов FunPay с открытым исходным кодом: меньше ручных действий, больше ясности в заказах и продажах.

FunPayFlow объединяет автоподнятие лотов, уведомления о заказах, историю продаж, статистику продаж и аналитику продаж в Telegram-панели. Он работает на Windows или на Linux-сервере. **VPS не обязателен:** он нужен, если бот должен оставаться включённым, пока домашний компьютер выключен.

FunPayFlow — независимый open-source проект и не является официальным продуктом FunPay. Интерфейс управления в Telegram в v1.0 доступен только на русском языке; выбор RU/EN в Windows-установщике меняет язык установки и запуска, но не Telegram-панели.

## Быстрый старт

**На Windows:** откройте [последний релиз FunPayFlow](https://github.com/Vetal12350/FunPayFlow/releases/latest), скачайте файл вида **`FunPayFlow-vX.Y.Z.zip`** из раздела Assets и распакуйте его. Файл GitHub «Source code (zip)» не является установочным архивом. Затем:

1. Откройте распакованную папку и запустите `Setup.bat`.
2. Пройдите настройку: введите данные FunPay и Telegram в скрытые поля. Установщик сам подготовит Python 3.13 и зависимости; вручную устанавливать Python обычно не требуется.
3. Запустите `Start.bat`, оставьте окно открытым и напишите своему боту `/start`.

Программа остаётся в распакованной папке; приватные настройки и база данных находятся отдельно в `%LOCALAPPDATA%\FunPayFlow`. Повторный Setup предлагает сохранить существующую конфигурацию. Если `winget` недоступен, может потребоваться установить [uv по инструкции Astral](https://docs.astral.sh/uv/getting-started/installation/).

**Нужна работа без домашнего ПК?** Следуйте [пошаговой инструкции по установке FunPayFlow на VPS](docs/VPS_INSTALL.md). Она начинается с выбора сервера и подключения через SSH.

> Автоматические действия изменяют ваш аккаунт FunPay. Перед включением проверьте тексты автоответов и правила площадки. `SAFE_MODE` блокирует автоматические изменяющие действия.

## Возможности

| Задача | Что доступно |
| --- | --- |
| Автоматизация | Автоподнятие лотов с учётом cooldown и ограниченными повторами; ночной автоответ; запрос отзыва после заказа. |
| Продажи | Уведомления о заказах, сообщениях и отзывах; сохранённая история заказов; статистика и аналитика продаж из SQLite. |
| Данные | Предпросмотр и импорт официального ZIP-экспорта FunPay с дедупликацией; отдельный учёт валют без сложения или автоматической конвертации. |
| Управление | Telegram-меню, десять встроенных модулей, статус, проблемы, журнал действий, логи и штатный перезапуск. |
| Надёжность | Блокировка второго экземпляра, сохранение состояния и очереди событий, `SAFE_MODE` и проверка перед изменяющим действием. |

Модули `autobump`, `notifications`, `night_mode`, `review_request`, `order_history`, `statistics`, `sales_analytics`, `sales_import`, `withdrawals` и `logs_ui` выбираются при первом запуске; изменение набора применяется после перезапуска. На новой установке все десять предварительно выбраны. Ночной автоответ и запрос отзыва имеют собственные выключатели.

История продаж сохраняется в SQLite. Историческая валюта заказа хранится отдельно от предпочтительной основной валюты. Аналитика фильтрует валюты, но не складывает USD, RUB и другие суммы вместе.

## Почему FunPayFlow

Один первый запуск через `Setup.bat` на Windows, управление через Telegram и отдельный каталог данных упрощают установку и обновление. Если нужен бот FunPay 24/7, тот же проект можно запустить на VPS через Linux-установщик и systemd. Исходный код открыт; у функций есть отдельные модули, которые можно отключить.

## Windows или VPS

| Где запускать | Когда удобно | Как начать |
| --- | --- | --- |
| Windows 10/11 | Первый запуск и работа, пока компьютер включён | Релизный ZIP → `Setup.bat` → `Start.bat` |
| Ubuntu VPS | Работа независимо от домашнего компьютера | [Руководство для новичка](docs/VPS_INSTALL.md) |

На Linux `linux/install.sh` устанавливает зависимости из `uv.lock` и может настроить службу `funpayflow.service`. Запускайте его обычным пользователем; `sudo` требуется только для установки службы. Подробные команды и безопасное обновление приведены в [VPS-руководстве](docs/VPS_INSTALL.md).

## Данные и обновления

Windows Setup/Start используют `%LOCALAPPDATA%\FunPayFlow` (при отсутствии `LOCALAPPDATA` — `%USERPROFILE%\AppData\Local\FunPayFlow`). Linux-установщик по умолчанию предлагает `~/.local/share/funpayflow`. Продвинутый пользователь может явно задать абсолютный `FUNPAY_BOT_DATA_DIR`; ручной запуск без переменной сохраняет прежнее размещение рядом с кодом. Автоматического переноса legacy-данных нет.

Перед обновлением **остановите бот и сохраните резервную копию каталога данных**. На Windows распакуйте новый релиз в новую папку, запустите новый `Setup.bat` с сохранением текущей конфигурации, затем новый `Start.bat`. Настройки, SQLite и логи остаются в прежнем каталоге данных; копировать их в папку программы не нужно. Для Linux следуйте [разделу обновления VPS-руководства](docs/VPS_INSTALL.md#12-обновление).

## Частые вопросы

**Нужен ли VPS?** Нет. Windows достаточно, пока компьютер и окно `Start.bat` работают. Для круглосуточной работы независимо от ПК полезен VPS.

**Нужно ли самому ставить Python?** Windows Setup и Linux-установщик готовят Python 3.13 через `uv`. При недоступном `winget` или `uv` может потребоваться установить `uv` вручную.

**Где настройки и база?** В приватном каталоге данных, отдельно от кода при обычной Windows/VPS-установке. См. [раздел о данных](#данные-и-обновления).

**Как обновить программу?** Остановите бот, сделайте резервную копию, затем используйте новый релиз с тем же каталогом данных. Инструкции: [Windows](#данные-и-обновления) и [VPS](docs/VPS_INSTALL.md#12-обновление).

**Бот не запускается или Telegram не отвечает?** Проверьте, завершён ли Setup, запущен ли только один экземпляр, верны ли локальные настройки и доступна ли сеть. Для VPS см. [диагностику](docs/VPS_INSTALL.md#14-частые-ошибки).

**Где сообщить об ошибке?** Обычные ошибки и предложения — в [GitHub Issues](https://github.com/Vetal12350/FunPayFlow/issues). Уязвимости сообщайте приватно через [GitHub Private Vulnerability Reporting](https://github.com/Vetal12350/FunPayFlow/security/advisories/new) по [SECURITY.md](SECURITY.md). Не прикладывайте секреты или приватные логи к публичным обращениям.

## Разработка

Для исходного checkout требуются `uv` и Python 3.13+:

```text
uv sync --locked --dev
uv run --no-sync pytest -q
uv run --no-sync python tests/packaging_smoke.py
```

Ручная локальная настройка: `uv run --no-sync python -m funpayflow.setup_config --data-dir <абсолютный_путь>`. Поддерживаемый entry point приложения: `uv run --no-sync funpayflow` или `uv run --no-sync python -m funpayflow.main`. Запускайте его только со своими настройками; команды выше для проверки кода не подключаются к FunPay или Telegram.

## Безопасность и лицензия

Не публикуйте `.env`, `bot_settings.json`, SQLite, экспорт продаж, логи и резервные копии. Секреты вводятся локально, а не в Telegram. Прочитайте [политику безопасности](SECURITY.md).

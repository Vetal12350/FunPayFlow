# Изменения

## FunPayFlow 1.0.0 — выпуск готовится

- Telegram-панель для продавца: уведомления, настройки, статус, проблемы и
  журнал действий.
- Автоподнятие лотов с cooldown, ограниченными повторами и защитой `SAFE_MODE`.
- Сохранённая история заказов и отзывов в SQLite; статистика и аналитика продаж.
- Раздельный учёт валют без сложения или автоматической конвертации.
- Импорт официальной истории продаж FunPay из ZIP с предварительной проверкой
  и дедупликацией.
- Настраиваемые запросы отзыва и ночной автоответ покупателям.
- Десять встроенных модулей, мастер первого запуска и штатный перезапуск из
  Telegram.
- Установка на Windows через Setup/Start с отдельной папкой данных; установка
  на Linux/VPS с дополнительным systemd-сервисом.

Текущий v1.0.0 Release остаётся черновиком. До публикации нужны оставшиеся
ручные проверки Linux/VPS и финальная проверка артефактов.
